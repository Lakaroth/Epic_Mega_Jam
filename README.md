# Director's Cut — 2026 Epic AI MegaJam

A short, cinematic spaghetti-western game made in Unreal Engine 5.8.4 for the
[2026 Epic AI MegaJam](https://itch.io/jam/2026-epic-ai-megajam) (theme: **DIRECTOR'S CUT**).

The player directs the cinematography: they switch camera angles during cutscenes and
during a high-tension duel, while still directly controlling the gameplay.

## What this repository is

This is the **public development journal and documentation** for the project. It is
**not** a mirror of the Unreal project. The game's source assets, purchased content,
MetaHuman source files, binaries and vendor packages stay private and local.
